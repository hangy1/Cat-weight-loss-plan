# Cat Calorie Calculator Frontend

A React + TypeScript frontend for the Cat Calorie Calculator API.

## Features

- Calculate daily calorie requirements for cats
- Support for different life stages (Indoor/Inactive, Neutered Adult, Intact Adult, Kitten)
- Weight goals (Weight Loss, Maintain, Gain Weight)
- Beautiful, responsive UI with gradient design

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- Backend API running on `http://localhost:8000`

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

This will start the development server at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Usage

1. Enter your cat's weight in kilograms
2. Select the life stage
3. Choose the weight goal
4. Click "Calculate" to get the daily calorie recommendations

## Tech Stack

- React 18
- TypeScript
- Vite
- CSS3 with modern gradients and animations
